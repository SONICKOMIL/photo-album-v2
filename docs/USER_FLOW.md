# Overview

Livara is designed to make collecting and sharing event memories effortless.

Every interaction is centered around a single event album that evolves from creation to becoming a permanent collection of shared memories.

> 🇷🇺
> Livara создана для того, чтобы сделать сбор воспоминаний максимально простым.

> Всё взаимодействие строится вокруг одного альбома мероприятия, который проходит путь от создания до постоянного архива воспоминаний.

---

# Actors

## Super Admin

Creates and manages event albums.

Responsible for platform administration.

---

## Organizer

Owns an event album.

Invites guests.

Configures album settings.

Moderates uploaded content.

Downloads media.

---

## Guest

Joins an album.

Views shared memories.

Uploads photos and videos.
